# 🏡 Maqueta Web para Cabañas, Tinajas & Hospedaje

Ejemplo de página web interactiva y moderna para alojamientos, cabañas, complejos turísticos y parcelas de descanso en **La Ligua, Valle Hermoso, Papudo y alrededores**.

### ✨ Características principales:
- **Cotizador Express de Estadía:** Huéspedes eligen cabaña, fechas de check-in y noches, generando una consulta formateada por WhatsApp.
- **Catálogo de Cabañas:** Detalle de capacidad, precios por noche, fotos y equipamiento.
- **Sección Destacada de Tinajas Calientes:** Tinajas a leña bajo las estrellas con llamado a la acción.
- **Guía de Atractivos Locales:** Distancias a Papudo, Ruta Textil de Valle Hermoso y Dulces de La Ligua.
- **100% Adaptada a Celulares (Mobile First):** Ideal para turistas que buscan desde su teléfono.

---
Sitio web de muestra desarrollado para prospección comercial en la Provincia de Petorca.
